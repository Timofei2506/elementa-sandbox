# Лицензия Unity для сборки в облаке (Personal, бесплатно)

Для сборки `.exe`/`.apk` в GitHub Actions нужна **активная лицензия Unity**. Логина и пароля
само по себе недостаточно — Unity требует файл лицензии `.ulf`. Ниже самый простой путь:
файл `.alf` сгенерируется прямо в Actions, а `.ulf` ты получишь в браузере за 2 минуты.

---

## Шаг 1. Добавь секреты e-mail и пароль

GitHub → репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

| Имя | Значение |
|---|---|
| `UNITY_EMAIL` | e-mail аккаунта Unity |
| `UNITY_PASSWORD` | пароль **без спецсимволов** (`"`, `\`, `$` ломают GameCI) |

`UNITY_LICENSE` пока не добавляй — его получим на шаге 3.

## Шаг 2. Сгенерируй файл активации `.alf`

1. **Actions → Unity license → Run workflow**
2. `action` = **request-file** → **Run**
3. Дождись зелёной галочки (1–2 минуты)
4. Внизу страницы запуска → **Artifacts** → скачай **Unity-Activation-File**
   (внутри файл вида `Unity_v6000.0.85f2.alf`)

## Шаг 3. Получи `.ulf` в браузере

1. Открой **https://license.unity3d.com/manual**
2. Загрузи скачанный `.alf`
3. Выбери **Unity Personal** → «I don't use Unity in a professional capacity» →
   укажи себя в категории дохода (до 100 000 $) → **Next**
4. Скачай файл **`.ulf`** (например `Unity_v6000.x.ulf`)

## Шаг 4. Добавь `.ulf` в секреты

1. Открой `.ulf` блокнотом — это обычный XML
2. Скопируй **всё содержимое** целиком (от `<?xml` до последнего тега)
3. GitHub → Settings → Secrets → **New repository secret**
   * Name: `UNITY_LICENSE`
   * Secret: вставь скопированный XML

## Шаг 5. Проверь

**Actions → Unity license → Run workflow → action = check-license**.
Зелёная галочка = лицензия рабочая. После этого любой пуш в `main` собирает `.exe` и `.apk`.

---

## Важно про места лицензии

У Personal-лицензии одно «место». Если Unity открыт у тебя на компьютере под тем же аккаунтом,
CI может не получить место:

* закрой Unity Editor и выйди из Unity Hub на ПК, пока идёт сборка, **или**
* заведи отдельный аккаунт Unity только для CI (рекомендую).

## Если что-то пошло не так

| Симптом | Решение |
|---|---|
| `Unable to get a valid Unity license` | секрет `UNITY_LICENSE` содержит не весь XML или файл от другой версии — повтори шаги 2–4 |
| `Activation failed: no seats available` | выйди из Unity Hub на ПК (см. выше) |
| `.alf` не создался | у аккаунта нет ни одной активации — сначала войди в Unity Hub локально один раз |
| `UNITY_PASSWORD` не принимается | смени пароль на буквы/цифры без спецсимволов |

## Альтернатива: лицензия без браузера

Если есть **Unity Pro/Plus** — вместо `.ulf` используются секреты
`UNITY_SERIAL` (вида `XX-XXXX-XXXX-XXXX-XXXX-XXXX`) + `UNITY_EMAIL` + `UNITY_PASSWORD`,
и `.alf`/`.ulf` вообще не нужны.

## Не отправляй пароль в чат

Пароль и e-mail добавляй **только** в GitHub Secrets. Если пришлёшь их мне — они попадут
в историю переписки, а это небезопасно. Технически я могу загрузить секреты через API,
но делать это надо только с «сервисным» аккаунтом Unity, а не с основным.
